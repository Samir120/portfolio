## Overview

NazerAuto is the website and workshop platform for Nazer Workshop, a car repair and spare parts business. Customers can browse services and parts, check what fits their vehicle, and order and pay online. The workshop manages its catalog, orders, and content from an admin dashboard.

The whole platform is bilingual, in English and Dari (Persian), including right-to-left layout and translated email notifications.

## The problem

The workshop needed one place to present its services and spare parts to customers who speak either English or Dari, take paid orders online, and manage everything without touching code.

## Architecture

The project is split into a React frontend and a Node.js API, both written in TypeScript.

**Backend:** Express, Sequelize, PostgreSQL, organized in layers:

- `controllers` and `routes` handle HTTP only
- `services` contain the business logic
- `integration` holds repositories and data access
- `models` define Sequelize models and DTOs
- `middleware` handles auth, errors, and language detection

Keeping HTTP, business rules, and data access separate means each layer can change without breaking the others.

**Frontend:** React, Redux Toolkit, Tailwind CSS, Vite, organized by role:

- `views` contain components, pages, and layouts
- `viewModels` are custom hooks that hold the logic for each view
- `models` contain the API client and shared types
- `store` holds the Redux slices

Pages stay focused on rendering, while the hooks own the state and API calls.

## Key features

- **Service and parts catalog** with search, filtering, and vehicle compatibility
- **Online ordering** with Stripe payments
- **Two-factor authentication** using TOTP, on top of JWT sessions and bcrypt-hashed passwords
- **Full bilingual support**: i18next on the frontend, language-aware middleware on the backend, and RTL layout for Dari
- **Bilingual email notifications** rendered from Handlebars templates
- **Admin dashboard** for services, orders, and site content
- **Responsive design** across mobile and desktop

## Deployment

The frontend is built with Vite into static assets. The backend compiles TypeScript and runs in production under PM2. Seed scripts set up the service catalog and the initial admin account.

## Outcome

NazerAuto is live at [nazerauto.com](https://nazerauto.com) as Nazer Workshop's public website. It gives the business an online presence in both of its customers' languages, a way to take paid orders, and a dashboard the owners can use to update services and content themselves.

## What I learned

**Bilingual means more than translated strings.** Supporting Dari affected the layout direction, spacing, and icons in the UI, and it reached the backend too: error messages and emails had to follow the user's language, not just the page.

**Payments and authentication need care at every step.** Integrating Stripe and adding TOTP-based two-factor authentication meant thinking about failure cases, secrets, and what the server should trust, not just the happy path.

**Structure pays off as a project grows.** Separating controllers, services, and data access on the backend, and views from view-model hooks on the frontend, kept features easy to add and bugs easy to locate.
